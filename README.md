# ZQ Forge Web

Public product, privacy, terms, and support pages for ZQ Forge apps.

| App | Home | Privacy | Support |
| --- | --- | --- | --- |
| JobPalm | `/jobpalm/` | `/jobpalm/privacy/` | `/jobpalm/support/` |
| FieldPalm | — | `/fieldpalm/privacy/` | `/fieldpalm/support/` |
| Refind / 拾图 | `/shitu/` | `/shitu/privacy/` | `/shitu/support/` |
| Sidewink | `/sidewink/` | `/sidewink/privacy/` | `/sidewink/support/` |

FieldPalm's terms and localized legal pages remain under `/fieldpalm/`. Refind / 拾图 also has terms and localized pages under `/shitu/`. JobPalm's product and promotion assets remain under `/jobpalm/`.

This repository is the new GitHub Pages source for `zqforge.com`. During staging, it intentionally has no `CNAME` file. Enable GitHub Pages from `main` at `/ (root)` and verify the preview before moving the custom domain from the old repository. Once GitHub Pages is configured with `zqforge.com`, GitHub will create the root `CNAME` file. Keep the old repository until the domain and all live URLs are verified.

App source code is maintained in separate repositories.
